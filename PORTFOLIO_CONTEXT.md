# 10. Project 01 --- Gas Burner Control Improvement

**Category:** Energy / Combustion / Continuous Improvement

Gas burner adjustment previously relied on ball valves. Investigated
replacing burner inlet ball valves used for adjustment with needle
valves to provide finer flow control.

Evaluation included: - Gas pressure - Flow behavior - Valve opening
characteristics - Burner operation - Gas consumption

**Measured trial result:** approximately **9.16% reduction in gas
consumption** under the tested condition.

Do NOT claim that the entire reduction was caused only by the valve
unless supported by experimental evidence.

Engineering value: - Energy efficiency - Better burner adjustment -
Improved controllability - Reduced operating cost - Data-driven
improvement

# 12. Project 03 --- Kiln Breakdown & Maintenance Improvement

**Category:** Maintenance / Troubleshooting / Reliability

A roller kiln experienced an urgent breakdown while production required
rapid restoration.

The repair team accelerated the work, but the repair method was not
sufficiently verified before returning the kiln to production. This
later contributed to ware movement becoming misaligned and created
downstream jamming risk.

Immediate countermeasure: - Balance motor speeds between kiln zones to
stabilize ware movement.

Key learning:

> Maintenance does not end when the machine starts running again.

Lessons: - Repair verification - Quality of maintenance -
Communication - Leadership accountability - Production pressure vs
maintenance quality - Root Cause Analysis

# 20. Technical Architecture

## Architecture Decision

Use a **frontend-only static Single Page Application (SPA)**.

Preferred stack: - React - TypeScript - Vite - Tailwind CSS

Do NOT introduce Next.js, a backend, database, authentication, or
external API unless a future requirement genuinely requires them.

Architecture priorities: 1. Reliability 2. Fast loading 3. Simple
deployment 4. Easy maintenance 5. Mobile responsiveness 6. Easy content
editing 7. Minimal external dependencies

## High-Level Architecture

``` text
Browser
   │
   ▼
React Application
   │
   ├── Pages
   ├── Sections
   └── Reusable Components
             │
             ▼
       Content / Data
   ┌─────────┼─────────┐
   ▼         ▼         ▼
Profile   Projects   Experience
             │
             ▼
        Static Assets
      Images / Documents
```

No runtime backend is required.
